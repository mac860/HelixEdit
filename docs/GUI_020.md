# HelixEdit 0.2.0 beta — Activity Rail and Vibrant Glass UI

## Implementation A: workspace navigation

HelixEdit 0.2 replaces the **visible top Sequence / Plasmid / Analysis ribbon** with a dedicated left-side activity rail. Each tile is generated with native Qt QPainter code and contains a saturated color, symbol and text label. No third-party application assets or SnapGene interface code are used.

| Activity | Accent | Canvas destination | Scrollable secondary panel |
|---|---|---|---|
| Sequence | Blue/cyan | Sequence | Sequence, Add, Rename, Remove, Insert Gap, Reverse, Translate, Find ORFs |
| Plasmid | Violet/magenta | Map | Map, Enzymes, Features, Primers, Addgene ID/import, Restriction, GenBank export, Assembly |
| Analysis | Emerald/teal | Local Tools | Tools, History, MAFFT, MUSCLE, BLAST+, Consensus, Identity Matrix, p-distance, Statistics, PHYLIP |

The context tool buttons use the **same QAction objects** as the menu commands. Tools are not reimplemented in duplicate. Shortcut behavior, undo/redo, sequence model and scientific algorithms are preserved.

A `QStackedWidget` named `workspaceToolStack` holds the three contextual panels. The existing `QTabWidget` named `studioTabs` still owns all seven real scientific pages; only its top tab bar is hidden. The panels' View buttons navigate to those original widgets. Calls from search and other tools to `tabs_->setCurrentWidget` still work. The activity state follows every programmatic tab change.

The lower activity buttons allow collapsing the context-tools panel and hiding/showing the project explorer; the explorer defaults to hidden for Plasmid and Analysis to maximize visual canvas, and shown for Sequence. View → Project explorer (`Ctrl+Shift+E`) exposes the same toggle.

## Implementation B: visual themes

Light, Dark and Dracula now receive a common 0.2 style layer with:
- Color-coded contextual action hover borders: blue Sequence, violet Plasmid, emerald Analysis
- Per-mode active tile outlines, gradient native icon tiles and subtle translucent navigation surfaces
- 15–19 px rounded panels, thin high-contrast edges and accessible focus indications
- Vibrant light gradient background; richly saturated dark and Dracula backgrounds
- Existing status bar, app SVG icon and independently branded About dialog retained

These are **glass-inspired Qt Widgets** surfaces using alpha colors and gradients. The application does not claim to blur the user's desktop window behind it. Contrast and legibility remain more important than extreme transparency.

## Behavior and preservation

- Old top ribbon is hidden rather than deleting its registered actions; a hidden `commandRibbon` object remains for backward compatibility with existing test lookup.
- All 7 views (Map, Sequence, Enzymes, Features, Primers, History, Tools) remain instantiated, with unchanged working editor pointers and scientific methods.
- No new package dependencies, network calls, scheduled tasks or scientific-data transformations are introduced by this layout.
- The source-based Git updater, APT-readable staging installer, and existing 14 offline sequence examples remain.

## Validation

Automated GUI assertions in `tests/editor_tests.cpp` check that:
- Activity rail contains Sequence/Plasmid/Analysis modes and contextual tool stack has exactly 3 pages.
- Seven scientific pages remain available but the redundant visible tab bar is hidden.
- Switching modes and selecting Map/Enzymes/Features/Primers/History/Tools routes to the correct view.
- Context actions exist, and tools/project panels can be collapsed.
- Light, Dark and Dracula CSS contains the activity-rail and per-mode styles.

**Important:** Changes are committed to the GitHub `main` branch, but a full Qt6 Ubuntu/macOS compilation, manual screenshot validation and end-to-end testing still need confirmation. This is a **0.2.0 beta source implementation**, not a verified binary release.

## Ubuntu 26.04 source upgrade

```bash
cd ~/Downloads/v3/HelixEdit
git pull --ff-only origin main
bash scripts/build_ubuntu_deb.sh
bash scripts/install_ubuntu_deb.sh
```

The generated package should be `build-ubuntu-amd64/HelixEdit-0.2.0-x86_64.deb` on Ubuntu x86_64. The install helper stages it in a temporary APT-readable path to prevent sandbox warnings. Restart HelixEdit to load the new layout.
