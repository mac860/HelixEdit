# HelixEdit 0.1.5 beta — responsive Wrap to Window

## Objective

Expose a compact, SnapGene-like sequence visualization that wraps the active record to the visible window width, without copying source code, assets, database content or proprietary user-interface elements from another product.

## Interaction

The Sequence tab has three saved controls:

- **Wrap to Window** — switches the central panel from the existing editable alignment table to `WrappedSequenceView`; its layout is recalculated on resize, using groups of 10 alignment columns.
- **Complementary strand** — DNA and RNA only. Displays the aligned 3′→5′ complement (A-T or A-U, G-C and standard IUPAC ambiguity complements). The primary row remains the original 5′→3′ sequence. RNA/protein records are not misrepresented as DNA.
- **Feature tracks** — displays directional feature ranges in colored lanes. Annotations remain attached to the underlying, ungapped record coordinates; the renderer converts those endpoints into alignment columns and clips them at line boundaries.

Clicking a wrapped residue selects its original row/column in the alignment model and synchronizes search and feature navigation. Double-clicking switches to the editable Grid at that location. The wrapped pane itself is read-only: all editing is handled by the original grid and undo logic.

The state is persisted with `QSettings`:

- `sequence/wrapToWindow` (default true for new installations)
- `sequence/showComplement` (default true)
- `sequence/showFeatures` (default true)

The same preferences are available through Settings → Preferences → Map & editing.

## Rendering and scientific considerations

The ruler groups alignment columns for consistent text layout, while displayed numeric coordinates use **ungapped** sequence positions. Gaps are never silently deleted or reinserted by this view. The complement is oriented opposite the primary strand as a visualization, not silently reverse-complemented or transcribed. Protein projects omit the complementary strand automatically.

The feature ribbons are preview tracks, not full GenBank editing/rendering parity. The UI displays the *active record* only in wrapped mode. For multi-sequence alignments, switch the checkbox off to edit and compare all rows at once.

The view is styled for Light, Dark and Dracula; it uses the same independent HelixEdit nucleotide/protein color semantics and responds to runtime theme changes.

## Test coverage

The Qt GUI tests exercise: control discovery, switched panes, preservation of the original sequence, resized viewport changes to `basesPerLine()`, optional complement and feature tracks, click hit testing, and return to the editable grid.

**Validation status:** Source and tests are committed to `main`. The 0.1.5 native Qt build and Ubuntu/macOS display behavior still require a successful CI or device build before publication as a verified release.

## Build on Ubuntu 26.04 x86_64

```bash
cd ~/Downloads/v3/HelixEdit
git pull --ff-only origin main
bash scripts/build_ubuntu_deb.sh
sudo apt install --reinstall ./build-ubuntu-amd64/HelixEdit-0.1.5-x86_64.deb
```

Then start HelixEdit, select **Sequence**, and enable **Wrap to Window**. Resize the main window or sequence panel to verify that the wrapped ruler and bases reflow.
