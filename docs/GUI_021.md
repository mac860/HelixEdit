# HelixEdit 0.2.1 beta — compact icon rail and vivid plasmid features

## Layout update

The existing Qt Widgets application now has a **56-pixel, icon-only left activity rail**. The modes retain their distinct colors and accessible names:

- **Sequence**: cyan double-letter base-pair tile
- **Plasmid**: violet circular tile
- **Analysis**: emerald sigma tile

Controls no longer repeat the mode name in the narrow rail. Their names appear in hover tooltips and remain exposed to assistive technologies via accessible names.

The first arrow button **toggles the secondary context tools sidebar**, rather than hiding the always-available activity rail. The control is synchronized with:

- **View → Tools sidebar**
- **Ctrl+Shift+S**
- **Settings → Appearance → Show context tools sidebar on startup**

The shared preference is `workspace/toolPanelVisible`, stored in local Qt `QSettings`. It defaults to collapsed on fresh installations for maximum sequence/map canvas width. Existing users retain their saved visibility. The project explorer's separate button and **Ctrl+Shift+E** continue to work.

The expanded tools panel remains 188 pixels wide and retains text beside icons for discoverability, while the persistent activity strip always uses icons only. Menu commands, keyboard shortcuts and scientific algorithms are unchanged.

## Circular map rendering

The old map drew a feature as a single 15-pixel arc on the backbone. That worked for simple demos but produced poor visibility and overlap with dozens of annotations. The updated map uses:

1. **Category-derived saturated colors**: promoters purple, origins gold, genes/CDS/resistance teal, terminators orange, primers pink, regulatory regions cyan, plus a deterministic colorful fallback.
2. **Concentric lanes** for overlapping feature intervals, with lane count based on actual map radius. The app sorts by real start positions and selects the first available lane where possible.
3. **Filled, strongly colored annular bands**, edged by darker strokes for contrast against both light and dark backbones.
4. **Direction-aware arrowheads**, drawn only when the true arc is physically long enough.
5. **Faithful short-feature markers**: small regions are shown as colored dots at the actual midpoint, never as artificially lengthened arcs.
6. **Existing source-derived labels** with 1-based presentation of the original zero-based/half-open positions. The mapper uses the active record only.

**Accuracy caveats:** These graphics visualize known annotations, not predicted biological functions. A plain FASTA file cannot supply a promoter, origin or gene annotation by itself; obtain a matching annotated GenBank file or add verified feature coordinates manually. Complex joined GenBank locations remain outside the simple interval model, and the renderer does not silently infer them.

## Regression coverage

New `tests/editor_tests.cpp` cases check:

- Activity rail width and icon-only button styles.
- Functional View menu sidebar toggle, Ctrl+Shift+S shortcut and persisted visibility.
- Accurate rendering of an origin annotation at known coordinates on a 1000 bp circular teaching construct; the sampled pixel must be vivid gold and differ from the no-features rendering.
- Clearing annotation data removes the expected colored band.
- Existing test coverage continues to check import synchronization, topology, restriction recognition, view switching and editing behavior.
