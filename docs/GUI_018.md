# HelixEdit 0.1.8 beta · Compact UI and icon-led About

## Motivation and screenshot findings

The user's Ubuntu 26.04 light-theme screenshots showed a large top tool region with duplicated actions, a persistent cream warning bar and a bottom row of redundant sequence-edit buttons. Together these reduced the visible Sequence and plasmid Map workspace.

The 0.1.8 refinement **does not alter the underlying sequence parser, topology, annotations or scientific computations**.

## Interface refinements

| Component | Before | After |
|---|---|---|
| Quick toolbar | Text beside most actions, ~17 px icons | Icon-first buttons, 16 px icons, shortened padding, tooltips preserved |
| Molecule / motif search | Separate "Workspace" strip | DNA/RNA/Protein selector + motif search + Find on the quick toolbar |
| Contextual ribbon | 67–79 px | 50–55 px, compact tabs and controls |
| Scientific warnings | Cream-colored full-width notification | Status-bar notice count and full tooltip; Help → Document notices… shows complete text |
| Sequence editing | Extra bottom row of Gap/Delete/Reverse/Translate buttons | Reclaimed canvas height; actions stay in menus and grid right-click context menu |
| About dialog | Plain text | Reused native app SVG icon, branded gradient hero, live version, contributor/links/actions |

The icon is rendered from the Qt resource if no application-window icon has yet been set (e.g. in headless GUI tests).

### Scientific notices

Warnings continue to be saved in \`Document.warnings\`. They are **not discarded** when the cream-colored banner is removed. The status bar displays a count and tooltip, and Help exposes the full text in a standard dialog.

### Remaining commands

The quick toolbar is **icon-first** to avoid hiding the large scientific canvas. Users can still access commands by their original File, Edit, Analysis, Cloning and Tools menu items. Keyboard shortcuts and underlying \`QAction\` objects are unchanged. Editable grid operations are also available by right-clicking.

### Tests and version

Added regression coverage in \`tests/editor_tests.cpp\` for:

- Compact toolbar, molecule selector and motif search, ribbon maximum height
- Warning label belonging to the status bar rather than the central canvas
- Custom About hero and SVG icon presence
- Developer name, email and GitHub link
- Functional Copy repository link action

**Status:** Changes are committed on GitHub \`main\`, but a completed native 0.1.8 compilation and offscreen GUI test run have not been observed here.

## Ubuntu 26.04 x86_64 build

\`\`\`bash
cd ~/Downloads/v3/HelixEdit
git pull --ff-only origin main
bash scripts/build_ubuntu_deb.sh
sudo apt install --reinstall ./build-ubuntu-amd64/HelixEdit-0.1.8-x86_64.deb
\`\`\`

After installing, restart HelixEdit, switch to the Light theme if needed, and test Sequence and Map at smaller and larger window sizes. Scientific notes remain visible under **Help → Document notices…**.
