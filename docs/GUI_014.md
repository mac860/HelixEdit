# HelixEdit 0.1.4 beta · Refined visualization & native installation

## Legacy identifier cleanup

Biopython's orchid tutorial file includes old `gi|...` FASTA headings. These are historical identifiers, not modern GenBank accession-version IDs. HelixEdit's 0.1.4 bundled teaching examples now use compact names such as `Cypripedium_lichiangense_Z78529.1`, preserving accessions and nucleotide sequences. This is **metadata modernization**, not a claim that historical orchid fragments are newly sequenced. Source: Biopython tutorial `ls_orchid.fasta`; records with IDs `Z78533.1` etc.

## Visual scientific output

- FASTA examples open in the **Sequence** tab instead of a blank-looking linear plasmid map. FASTA is a plain-text interchange format, not a formatted report.
- Sequence colors adapt to Light, Dark and Dracula themes.
- The new **base composition chart** displays nucleotide A/C/G/T(U)/Other, or amino-acid hydrophobic/basic/acidic/polar/other categories for the active record.
- **Analysis → Sequence statistics** displays a graphical table with GC% bars, biological length, alignment columns, gaps and ambiguous counts, plus TSV copy.
- The **Light** theme uses rounded translucent cards, a subtle sidebar shadow, lavender-blue gradients and teal/coral accents. These are rasterized Qt Widget effects; no operating-system compositor blur is claimed.

## Source updater behavior

The existing `scripts/update_from_source.sh` continues to pin updates to the same official GitHub origin: `https://github.com/mac860/HelixEdit` on `main`, refusing modified tracked files, non-fast-forward histories, or unexpected repository origins.

Settings and the Update dialog first use the saved local checkout. If none is saved, a shallow scan searches the working directory, home, `Downloads`, and common subfolders including paths such as `~/Downloads/v3/HelixEdit`. The app **does not re-clone the repository or automatically schedule updates**. The user explicitly approves source synchronization, compilation, tests and the privileged local DEB installation.

A fresh first installation still requires downloading/cloning the source once. If automatic discovery cannot locate a user-defined path, select that existing directory in Settings.

## Launcher and icon

The supplied `helixedit.svg` is already the original project icon; the SVG is preserved unchanged. The package also installs it at:

- `/usr/share/icons/hicolor/scalable/apps/helixedit.svg`
- `/usr/share/pixmaps/helixedit.svg`

The `org.helixedit.desktop` entry is installed at `/usr/share/applications`. Qt sets its desktop file identifier to `org.helixedit` and renders the SVG into the application/window icon. The Debian package post-install action refreshes icon and desktop caches if the necessary system utilities are available. GNOME may still require reopening the application launcher, or unpinning/re-pinning an older dock favorite.

## Validation before publication

1. On Ubuntu 26.04 x86_64, compile from the updated `main` branch and run CTest.
2. Load the 6 DNA / 3 simulated RNA / 5 protein examples and confirm all labels are concise, data lengths <=400, and the composition view is nonempty.
3. Use Analysis → Sequence statistics on nucleotide and protein datasets; inspect GC bar values and TSV copy.
4. Select Light theme and inspect rounded panels on high/low DPI screens.
5. Run `dpkg-deb --contents` against the generated 0.1.4 DEB to confirm desktop launcher, icons, examples and updater script.
6. Install the DEB, inspect the Ubuntu launcher and running window icon, then launch `helixedit`.
7. Verify Update defaults to the original clean checkout and safely reports no new commits when current; check that permission dialogs only occur at install time.
8. Run the native ARM64 and macOS CI matrix before issuing a public release.

**Status:** these are committed source changes, but this document is not a claim that a native 0.1.4 compile or cross-platform GUI test has passed.
