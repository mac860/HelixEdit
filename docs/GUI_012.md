# HelixEdit 0.1.2 — Compact Studio GUI (development)

HelixEdit remains an independent Qt 6 / C++17 application. The compact workspace is inspired by familiar scientific editing *workflows*, not third-party source code, branding, icons or assets.

## Layout

- **Quick actions:** Open, Save, Undo, Redo, Copy FASTA selection, paste FASTA, and add sequence.
- **Small contextual command strip:** Home, Sequence, Plasmid and Analysis. Buttons invoke the same actual actions as the menus; unavailable commands are not mocked.
- **Left project navigator:** filter and select sequences. It displays each record's length and circular/linear topology.
- **Map:** circular or linear renderer with feature arrows, exact recognition-site labels, and controls for visibility and zoom. Map SVG export remains supported.
- **Sequence:** editable multi-record alignment matrix, gap/reverse-complement controls, translation.
- **Enzymes:** browse the recognized positions of the eight built-in motifs; filter, inspect the full report and jump to the aligned position. Not an enzyme-cut or digest simulator.
- **Features:** inspect feature name, type, coordinates and strand; add annotations and export simple annotated GenBank.
- **Primers:** local CSV primer library, exact IUPAC-aware binding matches, and optional external Primer3 design. Primer3 must be installed separately.
- **History:** interactive undo history plus the most recent 1 MiB of the locally stored alignment/BLAST+ provenance log. The full log is retained on disk.
- **Tools:** optional local MAFFT/MUSCLE alignment workflow and tool settings; BLAST+ remains available from the Tools menu.
- **Appearance:** Light, Dark, and Dracula.

## Scientific limits

1. Restriction-site visualization uses **eight exact motif definitions**. It does not represent the much larger catalog and detailed enzyme properties available from commercial plasmid editors; no cut-offsets or double-digest simulation.
2. GenBank handling supports simple feature intervals; complex join/complement locations and full GenBank metadata do not round-trip.
3. Circular feature layout is a readable exploratory view, not a publication-validated graphical sequence map for all sequence lengths or annotation densities. It can reduce displayed labels for clarity.
4. The BLAST+ preview is synchronous and may freeze the UI temporarily. It uses a pre-existing local database, never silently uploads sequences.
5. MAFFT, MUSCLE, BLAST+ and Primer3 are separate, optional local tools. PHYLIP export is interoperability support, not tree inference.
6. No proprietary SnapGene code, media, logos, license mechanisms or database assets are included.

## Build and GUI validation

For Ubuntu 26.04 x86_64, use:

\`\`\`bash
sudo apt update
sudo apt install -y build-essential cmake ninja-build pkg-config qt6-base-dev qt6-svg-dev dpkg-dev
git pull --ff-only origin main
bash scripts/build_ubuntu_deb.sh
\`\`\`

The script configures a clean architecture-specific build, runs CTest using the offscreen Qt platform and packages a \`.deb\`. GUI tests assert the new tab order and working navigator, feature and map-zoom controls. GitHub Actions is configured for Linux x86_64, Linux ARM64 and macOS ARM64, with separate headless map and alignment screenshots.

**Verification status:** Source changes are committed to \`main\`, but a completed compiled 0.1.2 build/CI run and interactive desktop validation have not been independently observed here. Do not publish a signed release or describe 0.1.2 as tested on all target devices until those checks pass.
